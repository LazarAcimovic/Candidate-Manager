# Active refactor campaigns

> Open campaigns live as individual files in this folder. Read this index
> first, then only the campaign file you are working on. **Resume at the
> first unchecked subtask** and tick it in the same commit as its work.
> A campaign file still being here does not mean nothing has been done.

Progress counts subtasks; a subtask counts as done only when every one
of its boxes is ticked.

`What's left` describes the *remaining* work in a dozen words or so; it
never restates the count, and it only changes when the shape of what
remains changes.
